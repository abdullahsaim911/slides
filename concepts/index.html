Synapse — design concepts

Four complete visual worlds built from the same real content. Each has three live slides: the title, the problem and the animated system architecture. Open one, press → to step through, F for fullscreen.

A · The Catalog DrawerEach slide is a typed library index card with ruled lines, a rod hole and coloured divider tabs. Warm, tactile, bookish.
B · The Audio Description ScriptThe deck as the script that describes a lecture to a blind listener: timecodes, slug lines, highlighter, a screenplay page.
C · The Blueprint SheetAn engineering drawing: cyanotype grid, sheet border with zone references, title block, dimension lines and callouts.
D · The Colour-Block PosterA bold Swiss-style poster: huge cropped type, flat colour blocks, solid shapes and hard edges. Loud and confident.
